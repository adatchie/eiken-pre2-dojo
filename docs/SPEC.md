# 英検準2級 タイピング道場 — 設計仕様 v1

確定仕様（2026-08-03 adatchieさん承認済）に基づいた実装仕様。

## 基本方針
- ターゲット: 中学生の子供（iPad / iOS Chrome・Safari）
- 試験日: 2026-10-03（2026年度第2回一次）
- 入力方式: **タイピングのみ**（4択全廃。リロード暗記逃げを防ぐため）
- 書き取りOCR: 本編では使わない（週次テストの選択モード程度）
- デプロイ: GitHub Pages（静的・vanilla JS・localStorage）

## データ
- `data/words_pre2.json` — 準2級単語1500語（wordbook-passtan流用）{id,en,ja}
- `data/idioms_pre2.json` — 頻出熟語362件 {id,en,ja,ex,cat,tier,src}
  - tier A=163（複数ソースで頻出確認）/ B=176 / C=23（補強）

## セッションエンジン（逃げ場ゼロ）
1. 毎日0時に新規セッション生成。出題順は日付シードで固定（同日リロードで順序不変、翌日完全シャッフル）
2. 進捗はlocalStorageに**1問ごと**保存。リロード→同じ問題・同じ順番・同じ途中経過に復帰
3. 間違えた問題はキュー末尾へ再投入。全問正解するまでセッションは終わらない
4. 「答えを見る」= ミス2回分の記録 + その問題がセッション中にもう1回追加で出る
5. 1問20秒タイマー。タイムアウトはミス扱い（即座にキュー再投入）
6. セッション完了後にのみ「今日のクリア」報酬

## 出題形式（タイピング）
- 表示: 日本語意味＋例文（熟語は例文の該当箇所を空所化）
- 入力: 英語（熟語は en パターン本身。"take A for B" のようなプレースホルダ込み）
- 判定: 正規化後完全一致（小文字化・trim・空白圧縮・句読点無視）
  - "(just) in case" → "in case" / "just in case" 両方正解
  - "make(earn) a living" → 両方正解
- 厳格判定。部分点なし

## SRS（間隔反復）
- 正解: 間隔 1→3→7→14→30日（簡易SM-2）
- 不正解: 間隔リセット→翌日以降のセッションに再登場
- 毎日: 新規単語20語 + 復習期限到達分をセッションに投入（上限60問/日）

## ごほうびループ（ポジティブ設計）
- コイン: 正解+10（ストリーク倍率x1→x2→x3）、セッション完了+50
- デイリーログインボーナス: 7日カレンダー、7日目=レアカードパック
- ストリーク: 連続学習日数
- XP・ランク: 経験値でランクアップ（見習い→初段…）
- カード図鑑: マイルストーン（学習語数・ストリーク）でカード解放

## 週次テスト＋保護者リポート
- 週次テスト: 今週の間違い問題+SRS期限分から20問、計時実施
- 保護者リポート: 正答率・学習日数・弱点リストの簡易サマリ画面

## 技術メモ
- iOS Safari対策: TTSは使わない方向（本版はタイピング特化で音声不要）
- ファイル分割: storage / session / srs / rewards / report / ui / main
- fetch()でデータ読込（GitHub Pagesはhttp配信なので動作。file://は非サポート）
